YAML 错误百科

直接回答

多数 YAML 故障来自缩进、缺冒号或类型强制转换。在本索引中匹配错误信息，修好结构后用 YAML 1.2 解析器重新校验。

如何使用

按错误信息打开对应英文 Q&A，修复后用 在线校验 复核。中文专题页后续会补充独立译文。

Q&A 索引

快速排查清单

  • Tab 换成空格，缩进宽度统一。
  • 映射键后必须有冒号；同行值前保留空格。
  • 字符串中的冒号必要时加引号。
  • 每改一处就重新校验，避免行号漂移。

按症状分类

  • 解析失败：mapping values are not allowed / expected key — 先查缩进与冒号。
  • 运行时类型不对：开关变成布尔、版本号变成数字 — 加引号并阅读 1.1/1.2 指南。
  • 语言导入失败：Python 未安装 PyYAML、Go 依赖版本混乱 — 见语言专题与 Q&A。
  • 生态拒绝：kubectl/ansible 报 schema 错 — 语法通过后用生态 dry-run。

推荐修复闭环

  1. 复制完整报错信息，在本页或 Q&A 定位文章。
  2. 按正反例改文件。
  3. 用 YAML.cc 再校验；需要时打开 Multi-doc / Schema。
  4. 提交前让 CI 的 yamllint / 生态检查再跑一遍。
