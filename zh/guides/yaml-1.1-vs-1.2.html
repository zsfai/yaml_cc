YAML 1.1 与 1.2

直接回答

YAML 1.1 常把 yes/no/on/off（有时包括 NO）解析为布尔值；YAML 1.2 核心/JSON schema 通常把它们当字符串。对歧义标量加引号，布尔值优先写 true/false。

为何重要

不同语言库对 1.1/1.2 行为不一致。国家代码 NO、开关词 yes/no 在跨工具传递时容易被改写类型。

更安全的写法

country: "NO"
enabled: true
legacy_flag: "yes"

库行为提示

  • PyYAML 常偏 YAML 1.1 真值规则。
  • js-yaml 对许多标量更接近 YAML 1.2 JSON schema。
  • 以生产环境实际加载库为准做一次对照测试。

跨语言对照建议

同一份未加引号的 country: NO，在偏 1.1 的解析器里可能变成 false，在 1.2 JSON schema 下更常保持字符串。上线前用「将要用于生产的那个库」跑一次加载测试。

# 更安全
country: "NO"
enabled: true
flag: "yes"

本站工具如何配合

在 YAML 工具 中选择 YAML 1.2 或 1.1-aware：1.2 使用更接近 JSON schema 的解析；1.1-aware 会对 yes/no/on/off 给出警告。
