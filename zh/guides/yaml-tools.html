YAML 工具全景

直接回答

隐私粘贴检查用浏览器工具，仓库风格规则用 yamllint，批量转换与查询用 yq 或各语言库。YAML.cc 不会上传你的文件。

  • 校验 / 格式化 / 转 JSON

yq -o=json '.' config.yaml

推荐工作流

  1. 能开 Schema 的编辑器优先开（K8s、Compose、Actions）。
  2. 用 YAML.cc 做隐私粘贴语法检查。
  3. CI 中用 yamllint 统一风格。
  4. 再用生态专用检查（kubectl dry-run、ansible syntax-check 等）。

YAML.cc 工具能力

  • 语法校验、格式化、转 JSON（浏览器本地）。
  • Multi-doc：按 --- 拆分多文档。
  • YAML 1.2 / 1.1-aware 模式与真值警告。
  • 可选 JSON Schema 校验（Ajv，仍在本地执行）。
  • JSON/TOML/JSONL 等互转页面。

与 CLI 的分工

在线工具适合临时、含敏感信息的粘贴检查；仓库级规则用 yamllint；结构化查询用 yq；领域正确性用 kubectl/ansible 等原生命令。

YAML.cc

面向开发者的 YAML 校验、格式化与转换工具。处理均在浏览器本地完成。
