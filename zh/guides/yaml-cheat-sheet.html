YAML 速查表

直接回答

YAML 用缩进表达结构：键值映射、短横线列表、| 字面量块、> 折叠块，以及 &/* 锚点与别名。缩进只能用空格。

标量

string: hello
quoted: "1.0"
literal: |
  line1
  line2

集合

list:
  - a
  - b
map:
  key: value

锚点 / 别名

defaults: &defaults
  retries: 3
service:
  <<: *defaults
  name: api

引号规则（速记）

  • 看起来像布尔或数字、但实际要当字符串的值，请加引号（如 "NO"）。
  • 需要保留换行用 |；希望折行变空格用 >。
  • 缩进只能用空格，不能用 Tab。

多文档与指令

%YAML 1.2
---
kind: ConfigMap
metadata:
  name: a
---
kind: ConfigMap
metadata:
  name: b
...

启用工具的 Multi-doc 选项后，可用 --- 分隔的多文档一起校验与转 JSON（输出为数组）。

合并键（实现相关）

部分实现支持 << 合并键。它不属于所有 1.2 解析器的必选行为，生产配置请确认运行时库是否支持，并优先用显式字段减少魔法。
