按语言使用 YAML

选择对应语言的维护中库，对不可信输入使用安全/类型化加载，并在部署前校验文件。

  • JavaScript / TypeScript

返回指南

选库原则

优先使用官方或社区主流维护的库；对不可信输入使用安全/类型化 API；加载后再做业务字段校验。

各语言注意点速览

  • Python：安装包名 PyYAML，导入名 yaml；优先 safe_load。
  • JS/TS：js-yaml；注意浏览器与 Node 版本一致。
  • Go：优先 gopkg.in/yaml.v3，用结构体 tag 建模。
  • Java：SnakeYAML；不可信输入限制类型。
  • Rust：serde_yaml + serde 派生。
  • C#：YamlDotNet 反序列化到类型。

详细示例见各语言页；歧义标量见 1.1 与 1.2。
