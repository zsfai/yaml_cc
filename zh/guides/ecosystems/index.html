按生态使用 YAML

生态配置是带领域语义的 YAML。先保证语法正确，再用各生态的 dry-run/校验工具。

  • Kubernetes
  • Docker Compose
  • GitHub Actions
  • Ansible
  • OpenAPI

返回指南

校验顺序

  1. YAML 语法（缩进、冒号）。
  2. 生态 dry-run / schema。
  3. CI 策略检查（镜像标签、资源限制等）。

生态检查命令速查

kubectl apply --dry-run=client -f deploy.yaml
docker compose config
actionlint .github/workflows/*.yml
ansible-playbook --syntax-check site.yml

这些命令检查领域语义；YAML 纯语法可先用 YAML.cc。
