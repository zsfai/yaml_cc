GitHub Actions YAML

直接回答

GitHub Actions 配置通常以 YAML 表达。保持缩进一致，应用/部署前校验，并结合生态专用 dry-run 与通用语法检查。

典型片段

name: ci
on: [push]
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm test

校验建议

Workflow files live under .github/workflows/*.yml; quote strings that look like booleans.

此类文件常见坑

  • 嵌套键下缩进错误。
  • 未加引号的值被解析成布尔。
  • 从网页复制带入 Tab。

先用 YAML.cc 查语法，再用生态原生检查。

工作流文件位置

放在 .github/workflows/*.yml。表达式 ${{ }} 不是标准 YAML 类型，但对 Actions 运行时有意义——先保证 YAML 结构合法。

布尔与映射

on: push 与更复杂的 on: 映射不要混用错缩进。可用 actionlint 做额外静态检查。
