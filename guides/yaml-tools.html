YAML Tools Landscape

Direct answer

Use an in-browser validator for private paste checks, yamllint for repository style rules, and yq or language libraries for conversion and automation. YAML.cc tools never upload your file.

On YAML.cc

  • YAML validate, format, convert to JSON — private, in-browser
  • JSON to YAML
  • TOML to YAML / YAML to TOML

CLI essentials

# lint
pip install yamllint && yamllint config.yaml

# query / convert
yq -o=json '.' config.yaml

# python check
python -c "import yaml; yaml.safe_load(open('config.yaml'))"

When to use what

  • Quick paste check → YAML.cc online tools
  • Repo style rules → yamllint in CI
  • Schema shape (K8s CRD, JSON Schema) → editor + schema validators

Recommended workflow

  1. Edit in an IDE with YAML schema support when available (Kubernetes, Compose, GitHub Actions).
  2. Run a private paste check on YAML.cc for syntax.
  3. Enforce style in CI with yamllint.
  4. Apply ecosystem dry-run (kubectl, ansible-playbook --syntax-check).

YAML.cc advanced options

  • Multi-doc — validate and convert streams separated by ---.
  • YAML 1.2 / 1.1-aware — choose parse schema and surface legacy truthy warnings.
  • JSON Schema — optional Ajv validation entirely in the browser.
