GitHub Actions YAML

Direct answer

GitHub Actions configuration is expressed as YAML. Keep indentation consistent, validate before apply/deploy, and use ecosystem-specific dry-run tools plus a general YAML syntax checker.

Typical snippet

name: ci
on: [push]
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm test

Validation tips

Workflow files live under .github/workflows/*.yml; quote strings that look like booleans.

Common YAML pitfalls here

  • Indentation mistakes under nested spec/steps keys.
  • Unquoted values that become booleans in some parsers.
  • Copy-pasting tabs from chat or docs sites.

After editing, validate syntax on YAML.cc, then run the ecosystem-native checker.
